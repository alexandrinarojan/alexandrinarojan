### 📊 Projects

#### [InaVale Assurance – multi-layer analytics dashboard](https://github.com/alexandrinarojan/inavale-dashboard) · [Live demo](https://alexandrinarojan.github.io/inavale-dashboard/)

[![InaVale Assurance dashboard](https://raw.githubusercontent.com/alexandrinarojan/inavale-dashboard/main/dashboard-dark.png)](https://alexandrinarojan.github.io/inavale-dashboard/)

An interactive dashboard for a fictional insurance group, from “what happened” to “what we do”: 6 domains × 4 layers of analysis (descriptive, diagnostic, predictive, scenarios), in Romanian and English.

- **Data:** a consistent synthetic dataset I designed: 11 tables, 59,335 rows, star schema, generated in Python with fixed seeds, so it is reproducible
- **Analysis:** KPIs against targets, mix analysis (rate vs mix effect), 2026 forecasts with 80% prediction intervals
- **Scenarios:** what-if simulators for pricing, catastrophes and reinsurance, employee retention and solvency stress tests
- **Explainability:** every figure has context, every chart a written conclusion, every term a glossary entry (89 terms)
- **AI chat grounded in the data**, plus prepared answers in the public version
- **Engineering:** single-file HTML/JavaScript with Chart.js, automated tests with Playwright on 7 desktop widths and 5 mobile devices

`Python` `pandas` `NumPy` `Excel` `JavaScript` `Chart.js` `Playwright`
